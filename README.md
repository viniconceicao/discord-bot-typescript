# 🤖 Discord Bot — TypeScript & discord.js v14

Bot de Discord desenvolvido em **TypeScript**, utilizando **discord.js v14** e **Slash Commands globais**.

Projeto criado com o objetivo de estudo e prática de programação.

---

## 🚀 Funcionalidades

- `/ping` — Teste de resposta
- `/invite` — Convite do bot para outros servidores
- `/avatar` — Pegar avatar de um usuário
- `/banner` — Pegar Banner de um usuário
- `/ban` — Banir um usuário no servidor

---

## 🛠️ Tecnologias

- Node.js
- TypeScript
- discord.js v14
- tsx
- tsup
- dotenv
